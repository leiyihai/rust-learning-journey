# 第3课：数据类型

## 本课目标

- 掌握标量类型：整数、浮点数、布尔、字符
- 掌握复合类型：元组、数组
- 理解 Rust 的静态类型系统

## 概述

Rust 是**静态类型**语言：所有变量的类型在编译时就已经确定。

Rust 的数据类型分为两大类：
1. **标量类型**（Scalar）—— 表示一个单一的值
2. **复合类型**（Compound）—— 将多个值组合成一个

## 整数类型

| 长度 | 有符号 | 无符号 |
|------|--------|--------|
| 8-bit | `i8` | `u8` |
| 16-bit | `i16` | `u16` |
| 32-bit | `i32` | `u32` |
| 64-bit | `i64` | `u64` |
| 128-bit | `i128` | `u128` |
| 架构相关 | `isize` | `usize` |

默认整数类型是 `i32`，一般也用 `i32`。

```rust
let x = 42;         // 默认 i32
let y: u8 = 255;    // 显式指定 u8
let z = 1_000_000;  // 可以用下划线分隔数字
```

## 浮点数类型

```rust
let x = 2.0;       // 默认 f64
let y: f32 = 3.0;  // 显式 f32
```

Rust 中默认使用 `f64`（双精度），因为现代 CPU 上 f64 和 f32 速度差不多但更精确。

## 布尔类型

```rust
let t = true;
let f: bool = false;
```

布尔值只占一个字节。

## 字符类型

```rust
let c = 'z';
let z = 'ℤ';
let cat = '😻';  // Rust 的 char 是 4 字节，可以表示任何 Unicode 字符
```

## 元组（Tuple）

元组可以将多种类型的值组合在一起：

```rust
let tup: (i32, f64, u8) = (500, 6.4, 1);

// 解构
let (x, y, z) = tup;
println!("{x}, {y}, {z}");

// 索引访问
println!("{}", tup.0);  // 500
println!("{}", tup.1);  // 6.4
```

空元组 `()` 被称为**单元类型**（unit type），类似于其他语言中的 void。

## 数组（Array）

Rust 中的数组是**固定长度**的：

```rust
let a = [1, 2, 3, 4, 5];
let b: [i32; 5] = [1, 2, 3, 4, 5];
let c = [3; 5];  // [3, 3, 3, 3, 3]

// 访问
let first = a[0];          // 1
let last = a[a.len() - 1]; // 5
```

**注意**：数组越界访问在 Rust 中会触发 `panic!`（运行时错误），而不是继续读取无效内存。
