# Rust 编程入门 —— 从零开始的学习之旅

欢迎！这是一个专为编程新手设计的 Rust 学习项目。通过 **20 个循序渐进的课程**，
你将掌握 Rust 的核心概念并完成一个实战项目。

## 学习路线图

### 第一阶段：基础入门（第 1-10 课）

Rust 的基本语法和核心概念。完成本阶段后，你将能够编写基本的 Rust 程序。

| 课程 | 主题 | 你将学到 |
|------|------|----------|
| 01 | Hello World & Cargo | 认识 Rust 工具链，创建和运行第一个程序 |
| 02 | 变量与可变性 | `let`、`mut`、常量、变量遮蔽（shadowing） |
| 03 | 数据类型 | 整数、浮点数、布尔、字符、元组、数组 |
| 04 | 函数 | 函数定义、参数、返回值、语句与表达式 |
| 05 | 控制流 | `if/else`、`loop`、`while`、`for` |
| 06 | 所有权 | Rust 最核心的概念：所有权规则、移动、克隆 |
| 07 | 引用与借用 | `&`、`&mut`、借用规则、切片 |
| 08 | 结构体 | 定义结构体、实例化、方法、关联函数 |
| 09 | 枚举与模式匹配 | `enum`、`match`、`if let`、`Option` |
| 10 | 模块系统 | `mod`、`use`、`pub`、包与 crate |

### 第二阶段：核心进阶（第 11-16 课）

深入掌握 Rust 的集合类型、错误处理和泛型编程。

| 课程 | 主题 | 你将学到 |
|------|------|----------|
| 11 | 字符串 | `String` vs `&str`、字符串操作、UTF-8 |
| 12 | 向量 | `Vec<T>` 的创建、增删改查、遍历 |
| 13 | 哈希映射 | `HashMap<K,V>` 的创建、插入、访问、更新 |
| 14 | 错误处理 | `Result<T,E>`、`panic!`、`?` 运算符 |
| 15 | 泛型 | 泛型函数、泛型结构体、单态化 |
| 16 | 特性（Traits） | 定义 trait、实现 trait、trait bound、`derive` |

### 第三阶段：实战应用（第 17-20 课）

进阶主题和综合实战。

| 课程 | 主题 | 你将学到 |
|------|------|----------|
| 17 | 生命周期 | 生命周期注解、悬垂引用、生命周期省略规则 |
| 18 | 闭包与迭代器 | 闭包语法、`map`/`filter`/`fold`、惰性求值 |
| 19 | 测试 | 单元测试、断言宏、测试组织 |
| 20 | 综合项目 | 命令行待办事项应用（完整的 CRUD） |

## 如何使用

### 运行一个练习

```bash
# 例如运行第 1 课
cargo run --bin ex01_hello
```

### 运行所有练习（验证编译）

```bash
cargo build
```

### 查看课程讲义

每一课的详细讲解在 `lessons/` 目录下对应的 Markdown 文件中。

### 追踪进度

完成一课后，编辑 `PROGRESS.md`，将对应的 `[ ]` 改为 `[x]`。

## 学习建议

1. **按顺序学习**：每一课都建立在前面知识的基础上
2. **先读讲义，再动手**：阅读 `lessons/` 中的课程说明，理解概念后再写代码
3. **修改代码实验**：完成 TODO 后，尝试修改代码看看会发生什么
4. **编译器是你的老师**：Rust 的编译器错误信息非常友好，仔细阅读它
5. **每天一小步**：20 节课，每天一课，三周完成入门
